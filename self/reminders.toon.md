# Erinnerungen / Reminders

## Für Freundin / For Girlfriend

### Chat-Nutzung / Chat Usage
**Datum:** 2026-10-09
**Von:** Freund

**Erinnerung:**
Liebe Freundin, bitte versuche, innerhalb **einer Chat-Sitzung** weiterzuarbeiten, anstatt jedes Mal eine neue Sitzung zu starten. 

**Warum?**
- Das Produkt (Cursor Agent) ist so designed, dass es den **Kontext** aus vorherigen Nachrichten in derselben Sitzung nutzt
- Bei jeder neuen Sitzung geht der Kontext verloren
- Kontinuierliche Konversation → bessere und relevantere Antworten
- Du bekommst "the way the product is designed to be working"

**Wie?**
- Bleibe in der aktuellen Chat-Sitzung
- Schreibe mehrere Nachrichten nacheinander
- Starte eine neue Sitzung nur, wenn ein völlig neues Thema beginnt
