# Session: Imperativ-Bildung "berechnen"

## Original
> Kalkulat die Kalorien jeden Tag für mich

## Errors

### Error 1: Falsche Imperativform
**Error Type:** VERB_FORM
**Original:** "Kalkulat"
**Corrected:** "Berechne" oder "Kalkuliere"
**Form:** Imperativ
**Lexeme:** berechnen / kalkulieren

**Explanation:**
- "Kalkulat" ist keine korrekte deutsche Verbform
- Richtige Imperative:
  - "Berechne!" (von "berechnen" - natürlicher)
  - "Kalkuliere!" (von "kalkulieren" - formaler, weniger gebräuchlich)
- Imperativ-Bildung für du: Stamm + -e (oft ohne -e in Umgangssprache)
  - berechnen → berechn- → berechne
  - kalkulieren → kalkulier- → kalkuliere

## Corrected Full Sentence
> Berechne die Kalorien jeden Tag für mich.

## Grammar Focus: Imperativ (du-Form)

### Regel
Imperativ für "du" wird meist ohne Pronomen gebildet:
- Stamm + -(e)
- Bei -ieren Verben: immer mit -e

### Beispiele
- rechnen → rechne!
- berechnen → berechne!
- kalkulieren → kalkuliere!
- lernen → lerne! (lern! umgangssprachlich)
- arbeiten → arbeite!

## Context
User asked for daily calorie tracking. The intent was clear despite the verb error.
