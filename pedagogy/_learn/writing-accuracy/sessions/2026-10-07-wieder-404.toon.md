# Session 2026-10-07: Wieder 404 Fehler

## Original
"Wieder 404 Fehler, was ist los"

## Korrigiert
"Wieder ein 404-Fehler, was ist los?" oder "Wieder der 404-Fehler, was ist los?"

## Fehler-Tags

### ARTIKEL (fehlend)
- ❌ "Wieder 404 Fehler" → ✅ "Wieder ein 404-Fehler"
  - Unbestimmter Artikel "**ein**" fehlt
  - Oder bestimmter Artikel "**der**" (wenn auf vorheriges Problem bezogen)
  - Auch nach "wieder" braucht das Nomen einen Artikel

### KOMPOSITUM-SCHREIBUNG
- ❌ "404 Fehler" → ✅ "404-Fehler"
  - Bindestrich bei Ziffern-Komposita (wie zuvor schon korrigiert)

### SATZZEICHEN
- ℹ️ "was ist los" → "was ist los**?**"
  - Fragezeichen fehlt am Satzende
  - W-Fragen enden immer mit Fragezeichen

## Frame-Fokus: Artikel nach Adverbien (wieder, schon, noch)

### Regel
Auch nach temporalen Adverbien (wieder, schon, noch, nochmal) brauchen Nomen Artikel:

- wieder + **ein** + Nomen (unbestimmt)
- wieder + **der/die/das** + Nomen (bestimmt)
- noch + **ein** + Nomen
- schon + **der/die/das** + Nomen

### Beispiele
| Falsch (ohne Artikel) | Richtig (mit Artikel) |
|----------------------|----------------------|
| "Wieder Problem" | "Wieder ein Problem" / "Wieder das Problem" |
| "Noch Frage" | "Noch eine Frage" |
| "Schon Antwort" | "Schon die Antwort" |
| "Nochmal Fehler" | "Nochmal ein Fehler" |

### Bestimmt vs. Unbestimmt
- **Unbestimmt (ein/eine):** Neues oder unspezifisches Problem → "Wieder **ein** 404-Fehler"
- **Bestimmt (der/die/das):** Bekanntes/erwähntes Problem → "Wieder **der** 404-Fehler" (von vorhin)

### Übungen
1. Wieder ___ Auto kaputt. (das Auto - bekannt)
2. Noch ___ Frage? (unbestimmt)
3. Schon ___ Lösung gefunden? (die Lösung - bestimmt)

### Lösungen
1. Wieder das Auto kaputt / Wieder ist das Auto kaputt
2. Noch eine Frage?
3. Schon die Lösung gefunden?

## Kontext
Der Nutzer meldete erneut den 404-Fehler bei GitHub Pages. Das technische Problem bestand, weil GitHub Pages in den Repository-Einstellungen noch nicht aktiviert wurde (manuelle Aktivierung erforderlich).

## Notizen
- Wiederholung: Artikel fehlt (wie in vorheriger Session)
- Zeigt persistente Schwierigkeit mit Artikel-Verwendung
- Besonders in kurzen, frustrierten Meldungen werden Artikel weggelassen
- Typisch für umgangssprachliche Kommunikation, schriftlich aber wichtig
